# Dziennik (PWA)

## Wrzucenie na GitHub Pages
1. Załóż repozytorium (np. `dziennik`) na github.com, ustaw jako Public.
2. Kliknij "Add file" -> "Upload files" i przeciągnij WSZYSTKIE pliki z tego folderu
   (index.html, manifest.json, sw.js, icon-*.png) bezpośrednio do głównego katalogu repo. Zatwierdź "Commit changes".
3. Settings -> Pages -> Source: "Deploy from a branch", Branch: main, folder: / (root) -> Save.
4. Po 1-2 min pod adresem https://TWOJ-LOGIN.github.io/dziennik/ pojawi się aplikacja.

## Instalacja na Androidzie
Otwórz adres w Chrome -> menu (trzy kropki) -> "Zainstaluj aplikację".
